# Agent-Standarts

Центральный репозиторий общих стандартов для AI-агентов и механизм доставки этих стандартов
в сервисные репозитории. Не зависит от стека и от конкретного агента.

## Модель

- Общие правила живут **только здесь** (`rules/`). В сервис они попадают **копиями** в `.agent-rules/`:
  агенту не нужен доступ к центру, он читает локальные файлы.
- Универсальность по агентам обеспечивает `AGENTS.md` — общепринятый формат, который читают
  Codex, Cursor, Kilo, Copilot и другие. Строка «Прочитай `.agent-rules/workflow.md`» в нём обязательна:
  автоподгрузку по ссылкам не считаем надёжной.
- Команда `/check` — необязательный адаптер под клиента (`claude`, `kilo`, `cursor`).
  Для остальных агентов достаточно `AGENTS.md` и `bash .agent-rules/tools/check.sh`.
- Целостность доставленного проверяется хешами (`.agent-rules.lock`). Выполнение агентом правил
  хешами не доказать; это тема будущих evals.

## Владение файлами

| Кому принадлежит | Файлы | Доставка |
| --- | --- | --- |
| Центру (не редактировать в сервисе) | `.agent-rules/**`, `.claude/commands/check.md`, `.kilo/command/check.md`, `.cursor/commands/check.md`, `.agent-rules.lock`, `.agent-rules.version` | пишет и обновляет |
| Сервису | `AGENTS.md`, `CLAUDE.md`, `ci/`, `docs/`, `.agent-rules.json`, `.githooks/` | никогда не трогает |

Локально изменённый управляемый файл deliver не перезаписывает и не удаляет: он останавливается
с ошибкой и ничего не меняет. Правка вносится в центре и доставляется заново.

## Подключение сервиса

Нужны Bash, Git и Python 3.9+. Сети не нужно.

1. Скопируйте scaffold один раз (это ваши файлы, deliver их не трогает):

   ```bash
   cp -r <центр>/starter/. <сервис>/
   ```

2. Заполните `{{...}}` в `AGENTS.md` и допишите `read_first` / `docs` в `.agent-rules.json`.
3. Впишите проверки проекта в `ci/gate.sh` (lint, тесты, сборка) и удалите строку с маркером `GATE-UNCONFIGURED`.
   Пока маркер на месте, gate намеренно падает.
4. Доставьте стандарты. Сначала посмотрите план, затем запишите; `--agent` — по числу используемых клиентов:

   ```bash
   bash <центр>/delivery/deliver.sh <сервис> --dry-run
   bash <центр>/delivery/deliver.sh <сервис> --agent claude
   ```

   Выбранные клиенты запоминаются в `.agent-rules.lock`; повторный запуск без `--agent` их сохраняет.
5. Проверьте: `bash .agent-rules/tools/check.sh` (integrity → contract → `ci/gate.sh`).
6. Включите ранний хук: `git config core.hooksPath .githooks`.
7. Закоммитьте `.agent-rules/`, `.agent-rules.lock`, `.agent-rules.version` и команды клиента в репозиторий сервиса.
   Доставка сама ничего не коммитит.
8. Для Claude Code, который читает `CLAUDE.md`, создайте в сервисе `CLAUDE.md` со строкой `@AGENTS.md`.

Обновление: получите новую версию центра (`git pull`) и снова запустите `deliver.sh`.
В CI сервиса удобно держать `deliver.sh <сервис> --check` для обнаружения дрейфа.

## Команды deliver

```text
delivery/deliver.sh [СЕРВИС] [--dry-run | --check] [--agent claude|kilo|cursor ...]
```

- без флагов — записать; `--dry-run` — показать план; `--check` — код 1 при дрейфе или конфликте;
- источник — рабочая копия центра (теги и серверные политики пока не используются);
- устаревшие файлы удаляются только по прежнему lock и если хеш совпадает с доставленным.

Что доставляется, задаёт `delivery/manifest.txt`: строки `<источник> <назначение>`, назначение только под
`.agent-rules/` и каталогами клиентов; абсолютные пути и `..` отклоняются.

## Проверки

- В центре: `bash ci/gate.sh` (тесты на временных репозиториях).
- В сервисе: `bash .agent-rules/tools/check.sh`. Отдельно: `integrity.sh` (хеши, версия, executable)
  и `contract.sh` (ссылка на workflow, `read_first`/`docs`, gate не заглушка).

## Версионирование

SemVer в файле `VERSION`, изменения — в `CHANGELOG.md`.

- MAJOR — новые обязательные требования к сервисам;
- MINOR — совместимые дополнения;
- PATCH — уточнения формулировок.

## Структура

```text
AGENTS.md            инструкция для работы над самим центром
rules/               workflow, команда check, tools (integrity/contract/check/core.py)
clients/<клиент>/    команда /check для Claude Code, Kilo, Cursor
delivery/            manifest.txt, deliver.py, deliver.sh
starter/             заготовка для нового сервиса (единственный источник локального AGENTS.md)
tests/, ci/          проверки центра
```
