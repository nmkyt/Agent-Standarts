# AGENTS.md — центральный репозиторий стандартов

Этот репозиторий — источник общих правил для AI-агентов и механизм их доставки в сервисы.
Сам он **не потребитель**: общие правила лежат в `rules/`, а не в `.agent-rules/`.

## Правила работы

- Общие правила правятся только здесь: `rules/`, `clients/`, `starter/`, `delivery/`.
- Язык документации — русский. Инструменты: Bash и стандартная библиотека Python 3.9+, без зависимостей.
- Новый или переименованный файл, который нужно доставлять, добавляй в `delivery/manifest.txt`.
- Меняя обязательные требования, обнови `VERSION` и `CHANGELOG.md` по правилам из `README.md`.
- Коммиты, теги и push — только по просьбе пользователя.

## Проверки

```bash
bash ci/gate.sh
```

Запускает тесты на временных репозиториях без сети. Перед завершением работы gate должен быть зелёным.

## Не делай без просьбы

Теги и серверные политики, документы спек/трекера/wiki, субагентов, evals, новые зависимости.
